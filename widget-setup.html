My Finance Widget

วิดเจ็ตใช้ฟรีผ่าน Scriptable สำหรับหน้าจอโฮม iPhone

วงเงินบัตรเครดิต

ติดตั้งสคริปต์บัตรเครดิตโดยเฉพาะ → ไม่ต้องตั้ง Parameter

ใช้สคริปต์เดียวกัน เพิ่ม Widget Scriptable อีกอัน → เลือกสคริปต์ My Finance → ช่อง Parameter ใส่ cards แสดงวงเงิน ยอดใช้ไป และวงเงินเหลือใช้ของแต่ละบัตร พร้อมวงกลมเปอร์เซ็นต์ใช้วงเงิน

ขนาดเล็กแสดง 1 บัตร · กลาง 2 บัตร · ใหญ่ 3 บัตร เรียงตามชื่อ หากมีมากกว่านั้นจะแจ้งจำนวนที่เหลือ แตะเพื่อเปิดเมนูบัตรในเว็บ หากต้องการเจาะจงบัตร ใส่ cards:รหัสบัตร โดยใช้รหัสรายการจากข้อมูลสำรอง JSON ตาราง debts ช่อง id

วงเงินเหลือ = วงเงิน − ยอดใช้ไป อ้างอิงยอดที่บันทึกไว้ในเมนูบัตรและสินเชื่อ ไม่ได้เชื่อมยอดจากธนาคารโดยตรง จ่ายบัตรแล้วให้ตรวจยอดใช้ไปในแอปด้วย กรณีใช้เกินวงเงินจะแสดงยอดเกิน และเหลือใช้เป็นศูนย์ เว้น Parameter ว่างเพื่อใช้ Widget งบกินเดิม

  1. กด คัดลอกสคริปต์ ด้านล่าง
  2. เปิด Scriptable → กด + → วางสคริปต์ทั้งหมด
  3. ตั้งชื่อ My Finance แล้วกด ▶ เพื่อเข้าสู่ระบบด้วยบัญชีเดียวกับเว็บไซต์
  4. กลับหน้าจอโฮม → กดพื้นที่ว่างค้าง → เพิ่มวิดเจ็ต → Scriptable → เลือกขนาดกลาง
  5. กดวิดเจ็ตค้าง → แก้ไขวิดเจ็ต → ช่อง Script เลือก My Finance

Widget งบกิน แสดงงบคงเหลือ ยอดใช้ ยอดงบ และแถบสัดส่วน เช่น ใช้ 2,000 จาก 4,000 บาท = 50% หากยังไม่ตั้งงบจะแจ้งให้ตั้งงบก่อน

ถ้ามีสคริปต์เดิม: คัดลอกโค้ดใหม่นี้ → เปิดสคริปต์ My Finance เดิมใน Scriptable → แทนที่โค้ดทั้งหมด → กด ▶ แล้วเลือกอัปเดต / ดูตัวอย่าง ไม่ต้องเพิ่มวิดเจ็ตใหม่

กรอกรหัสผ่านเฉพาะในหน้าต่างของ Scriptable ไม่ส่งทางแชต ไม่ใส่ในโค้ด สคริปต์เก็บ session ใน Keychain และอ่านข้อมูลด้วยสิทธิ์บัญชีของคุณ ไม่ใช้กุญแจผู้ดูแลระบบ

กำลังโหลดสคริปต์…

อัปเดต 21 ต.ค. 2569: กรองบัตรที่ปิดใช้งานและเพิ่มสถานะอ่านข้อมูลสำเร็จพร้อมเวลา

สคริปต์ขออัปเดตอีก 10 นาที แต่ iOS เป็นผู้กำหนดเวลาทำงานจริง จึงอาจช้ากว่านั้นได้ ดูเวลาข้างคำว่า “สำเร็จ” เพื่อเช็กว่าข้อมูลใหม่เมื่อไร หากอัปเดตไม่สำเร็จจะแสดงเวลาอ่านสำเร็จครั้งก่อน ไม่เปลี่ยนเป็นยอดศูนย์

iPhone เป็นผู้กำหนดรอบอัปเดต ไม่ใช่เรียลไทม์ ยอดใช้เกณฑ์เดียวกับหน้าเว็บภาพรวม รวมรายการรอดำเนินการ/รายการในเดือนที่ตั้งวันที่ล่วงหน้าในงบ แต่ไม่รวมยกเลิก วิดเจ็ตทำให้คนที่เห็นหน้าจอเห็นยอดเงินได้ ควรใช้เฉพาะหน้าจอโฮมที่คุณสะดวกแสดงยอด

หากเลิกใช้: เปิดสคริปต์ใน Scriptable → ออกจากระบบวิดเจ็ต → ลบวิดเจ็ตจากหน้าจอ การออกจากเว็บอย่างเดียวอาจไม่ออกจากระบบวิดเจ็ต
